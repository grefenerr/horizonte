EQUIPE - DEVs

Visão computacional, ecologia e tecnologia aplicada para cidades mais inteligentes.

Quem somos

A equipe da SmartCam/OctaVision é formada por estudantes multidisciplinares que colaboram para criar um sistema inteligente de monitoramento e controle de tráfego com tecnologia de ponta.

Grefener & Clara — Visão Computacional

Grefener e Clara foram responsáveis pela implementação da visão computacional da IA utilizando YOLO, Python, Pandas, Ultralytics, Cvzone e OpenCV, detectando veículos essenciais para o projeto.

Motomoto — Front-end / App

Motomoto desenvolveu a parte front-end do aplicativo com Flet, Flutter, Python, HTML, JS e CSS, tornando a interface funcional e estilizada.

Isaac — Banco de Dados

Isaac implementou o banco de dados e criou validações rigorosas para login, cadastro e armazenamento das informações geradas pela IA usando PostgreSQL e pgAdmin 4.

Peixoto, Yukio & Angelo — Aplicação Web

Construíram a aplicação web usando Streamlit, HTML e CSS, integrando com PostgreSQL para escalabilidade e segurança.

Ailton — Maquete & Integração

Ailton lidera a maquete física, integrando sistemas inteligentes no Raspberry Pi, sincronizando IA com hardware e garantindo eficiência para demonstrações reais.

A colaboração entre as diferentes áreas torna a SmartCam/OctaVision robusta e pronta para oferecer soluções reais às cidades, auxiliando gestores públicos na tomada de decisões inteligentes e eficientes.
